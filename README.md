# AI-Powered Data Analytics Dashboard

## Project Overview

AI-Powered Data Analytics Dashboard is a web-based application that allows users to upload CSV or Excel datasets and perform data analysis, visualization, machine learning, and AI-based insight generation.

## Main Features

- User Registration and Login
- Secure Password Hashing
- CSV and Excel Dataset Upload
- Automatic Data Analysis
- Data Cleaning
- Missing Value Detection
- Duplicate Detection
- Outlier Detection
- Statistical Analysis
- Correlation Analysis
- Interactive Data Visualization
- Classification
- Regression
- Customer Spending Prediction
- Customer Clustering
- AI-Generated Insights
- Analysis History
- PDF Report Generation
